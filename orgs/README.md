# orgs/

An org is born one way: an account (signed up with the operator's one-time code) creates it at `/orgs/new`, on the
hosted platform or on your own install — [`docs/INSTALL.md`](../docs/INSTALL.md) §2, §4 and §5. A person joining an
org needs only its address and a key (or a sign-in) from its admin (§1). Its projects, people and seats:
[`engine/ORG-SETUP.md`](../engine/ORG-SETUP.md).
