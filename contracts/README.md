# contracts/ — the door's contract

The MCP and REST shapes the engine (`engine/`) serves to its callers.

- **`door.declared.json`** — hand-typed: the shapes a caller may rely on that no registry states (receipt fields, the
  eval-mark rule, run results, gate steps, error meanings, refusal classes).
- **`door.json`** — GENERATED by `engine/tools/make-door-contract.py` from the registries in `engine/src/index.js`
  (`MCP_TOOLS`, `CAPABILITIES`) merged with `door.declared.json`. The same run writes `engine/src/doorcontract.js`,
  which `GET /contract` serves. Never hand-edited: the gate regenerates both and diffs.

Every reader finds this directory the same way: `AGENT_R_CONTRACTS`, else `./contracts`, else `../contracts`
(proven by `engine/tools/relocate-selftest.sh`, a gate step).

A change: edit `door.declared.json` (or the registries), run `python3 engine/tools/make-door-contract.py`, and commit
both in the same slice.
